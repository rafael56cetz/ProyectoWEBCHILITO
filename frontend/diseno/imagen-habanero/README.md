# Fondo de El Chilito

Generado con la herramienta integrada de imágenes a partir de la captura del propietario. La imagen contiene solamente la fotografía reconstruida; los textos y botones pertenecen al HTML.

- Original de máxima fidelidad: `../../vista/img/habanero-fondo-original.png`.
- Archivo que utiliza la web: `../../vista/img/habanero-fondo.webp`.
- Resolución nativa: **1896 × 830 px**. El WebP conserva esta resolución y se exportó con calidad 94, sin recortar ni redimensionar.
- Referencia recibida: `referencia-captura.png`.
- Instrucción exacta de generación: `prompt.txt`.
- Huellas y datos de exportación: `origen.json`.

## Conservar al subir al repositorio

Incluir ambos archivos de `vista/img/`, esta carpeta de procedencia y los cambios en HTML/JS/CSS. La aplicación usa rutas relativas, sin depender de `/tmp` ni de la carpeta de imágenes generadas de Codex. Los archivos de imagen y su procedencia acompañan a esta carpeta dentro del repositorio.

No reemplazar los archivos por enlaces externos. Al copiar o publicar el frontend se deben mantener las imágenes junto con las vistas. El PNG permite volver a exportar la versión web sin regenerar la fotografía.
